Setup and Protocol

Models and streaming wrapper (shared by both benchmarks)

Qwen3.8-27Bthinking off, greedy (thinking-low rerun in progress)
Muse Glimmer 30Breasoning_strength=low, official sampling (T 1.0, top-p 0.95, top-k 64), seeded; greedy on Pro2Bench
Window8 most recent frames at 1 fps (long edge ≤ 672 px), media-time replay, never a future frame
MemoryJSON the model rewrites in a separate call, ≤ 512 tokens; the only state beyond the window
ServingQwen: vLLM. Muse: SGLang + DFlash + Meta's parser (reported); earlier plain-vLLM run shown for comparison. Efficiency: Efficiency page
HardwareUW Hyak Klone, preemptible H200 + A100 80 GB, shared resumable item queue

One replay step at media time t: public inputs up to t + own memory → benchmark answer, then a separate memory rewrite. Gold stays with the scorer.

Dataall 2,100 val sessions (700 per task; the scorers need all rows)
EgoLongQAone question after the video, no system prompt
EgoConvturn i answered when its interval ends, own earlier answers as history
EgoProactivedecision per ~8 s chunk: $interrupt$ … / $silent$, gold history (last 4 turns)
Our change8 recent frames + own memory where the kit puts frames; memory refresh every 2 s (10 s if > 10 min); 4,096-token budget
Scoringstarter-kit run_evaluation.py, unmodified

You are a helpful assistant answering questions about a video the user is watching. Answer directly and concisely based on what you see in the video. Do not start your response with phrases like "Sure!", "Of course!", "The answer is", or similar preambles. Just provide the answer.
EgoProactive: system prompt starter kit, verbatim; then the query and the last 4 gold dialogue turns
You are a proactive AI assistant watching a first-person video of the user performing a procedural task. The user has issued a single high-level query. As the video unfolds you observe a series of short (~8s) chunks; after each chunk you decide whether to speak or stay silent.

Output format (single line, no preamble):
  - If you should speak: start with the literal token `$interrupt$` followed by your suggestion or answer in plain text.
  - If you should stay silent: output the single literal token `$silent$` and nothing else.

Speak when the user asks you something, when an earlier action needs correction, or when you have useful, timely guidance for the next step. Stay silent when nothing useful needs to be said.
Memory update ours, a separate call; [context] = no question yet / turns so far / the user's query
You are watching a live first-person video but only ever see the most recent frames (each labeled with its time in seconds) plus a short written memory that you yourself wrote on the previous update. Nothing else about earlier footage survives, so the memory must carry everything you may need later: what the person did and where, objects and their locations, text you saw, counts, the current state, and what was said.
Context so far: [context]
Hard limits: observed_facts at most 8 entries, completed_steps at most 6, pending_commitments at most 3, uncertainties at most 3; every entry at most 15 words and prefixed with its time (e.g. "12s: ..."); current_state at most 40 words. Merge or drop older entries instead of exceeding these limits. Describe only what the frames support.
Reply with ONE JSON object and nothing else, in exactly this shape:
{"observed_facts": [...], "completed_steps": [...], "current_state": "...", "pending_commitments": [...], "uncertainties": [...]}

EgoProactive (Pro2Bench paper protocol)

System prompt App. G.2, verbatim
You are a helpful, proactive AI assistant guiding a user through a step-by-step procedural task. You observe the user’s activity through egocentric video from their perspective.

Your responsibilities:
1. Track which step the user is currently performing.
2. Detect when a step is completed and proactively announce the next step.
3. Detect mistakes or deviations from the expected procedure:
 - Skipped steps
 - Wrong step ordering
 - Technique errors
 - Substitutions or improvisations
4. When a deviation is detected, suggest a recovery action.
5. If no guidance is needed (user is progressing normally), stay silent.

Output format:
- If the user needs guidance (step completed, mistake detected, or question asked), respond with: $interrupt$ followed by your guidance.
- If no guidance is needed, respond with exactly: $silent$

Be concise. Focus on what the user should do next, not what they just did.
User message after the chunk's 8 frames; No-Plan duplex template, visual summary = our memory
Here is the summary of the recent visual context: {visual_summary}
Here is the most recent conversation between the user and the assistant:
User: {user_utterance}
Assistant: {assistant_response}

Observations

  • Native serving fits the budget: Muse over 300 s on 59 / 700 LongQA samples (plain vLLM: 699), so its with-rule LongQA accuracy goes 0.001 → 0.451, above Qwen's 0.411.
  • EgoProactive moved with serving: on plain vLLM Muse skipped reasoning on decisions (median 3 tokens) and interrupted in 98 % of chunks; natively it reasons (median 112) and stays silent more (silent recall 0.02 → 0.10, macro F1 0.36 → 0.43). Cause under investigation.
  • Pro2Bench prompt: Muse is balanced (G-mean 0.54) and Qwen nearly silent (0.26).
  • Long-video memory works better for Qwen (EgoLongQA 0.66, inside the zero-shot 7B range) than for Muse (0.49–0.52).
  • LLM judge (EgoConv): Muse on plain vLLM 0.359 (leaderboard best 0.59); Qwen and native Muse queued.
